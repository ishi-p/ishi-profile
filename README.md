# Ishi Pandeya | Personal Profile Webpage

A responsive personal profile webpage built with HTML and CSS and hosted on GitHub Pages.

**Live site:** https://ishi-p.github.io/ishi-profile/

## Sections
Profile photograph, About Me, Education, Projects, Skills, Achievements, Interests & Hobbies, and Contact details.

## Built with
- HTML5 for structure
- CSS3 (Flexbox, Grid, media queries) for styling and responsiveness
- Google Fonts (Fraunces, Work Sans)
